# T2 Group 8 — E-commerce GMV va Orders Forecasting

PDP University 4-kurs jamoaviy loyihasining maqsadi tarixiy buyurtma ma’lumotlari asosida haftalik GMV (savdo aylanmasi) va buyurtmalar sonini prognoz qilishdir.

| Papka | Vazifasi |
| --- | --- |
| `config/` | Loyiha va tajriba sozlamalari |
| `data/` | Mahalliy xom va qayta ishlangan ma’lumotlar |
| `reports/` | Tahlil hisobotlari va grafiklar |
| `sql/` | Ma’lumot ajratish va haftalik agregatsiya so‘rovlari |
| `src/features/` | Modelga kiradigan belgilarni tayyorlash |
| `src/models/` | Prognoz modellari |
| `src/evaluation/` | Vaqt bo‘yicha baholash va metrikalar |
| `tests/` | Avtomatlashtirilgan testlar |

Python 3.12.7 muhitida bog‘liqliklar `requirements.txt` orqali o‘rnatiladi.
